# Patches on nc-ui 0.1.0 (commit 7d9bb4e)

The tree started as Astrid's standalone package (MIT, Peter Semmelhack, https://psem.me/).
Nine Rhythm changes sit on top:

1. `patches/nc-ui-rhythm-domain.patch` (upstreamable). Fills `component.rhythm` in `tokens/tokens.json`, documents it in `docs/domains/rhythm.md`, and updates the build test that expected the domain to stay empty. Names match unpublished branch `petra/rhythm-renames-filter-roles`: `module-gap`, `control-gap`, `label-leading`, `step-gap` (the old `gap-tight`, now 2px), palette `lane-1`…`lane-4`, and semantic `filter-lowpass` / `filter-highpass` / `filter-bandpass` (`--nc-ui-filter-*`) in place of `synth.filter-*` and `rhythm.filter-*`. Motion roles `motion-fade` (.2s ease), `motion-fade-out` (.25s ease-out), and `motion-slide` (.22s ease-out) are semantic tokens in the same tree. Regenerate outputs with `node scripts/build-tokens.mjs`.
2. `patches/nc-ui-touch-slots.patch` (upstreamable, on top of this vendor). Long-press Save and Clear on slots (Clear asks first; Shift-click and Option-click stay), a visible Accent mode on the step grid, coarse-pointer hit pads capped at `target-min`, keyboard knobs (`role=slider`, arrow keys, Page Up and Page Down, Home and End, Shift for a fine step, focus ring from `focus-ring`), the desktop module row at 1024px, and the motion rule: a button press scales to .985 on `transition-feedback`, fades and the Undo toast use the motion tokens, `prefers-reduced-motion: reduce` turns those off, and `MODULATED_SELECTOR` (`[data-modulated], [data-modulated] *`) forces `transition: none` while an external source drives the value. Slider thumbs and meters stay un-transitioned. It also carries `createToast` (`src/primitives/toast.js`, from nc-ui `feat/toast` db832b1 plus its v2 fixes, read through `alias.js`), the `toast-*` semantic tokens and constant `toast-duration`, and the `.nc-ui-toast` chip rules in `kit.js`. A module header's status message (`.nc-snap-msg`) wraps onto its own line under the title instead of truncating, so neither one is cut at 360–390 px or in a narrow desktop column. An empty message keeps the header on one row. Apply it from the nc-ui root with `patch -p1`.
3. `patches/nc-ui-playhead.patch` (upstreamable, on top of 1 and 2). The shared playhead: semantic `playhead` (`{color.accent}`, #003153), `playhead-width` (`{border.thick}`, 2px) and `playhead-offset` (`{border.hairline}`, 1px), so Bass and Rhythm draw the playing step the same way (Bass's method: an accent ring one hairline outside the pad). `rhythm.playhead` now refs `semantic.playhead` (was `semantic.text`), and `kit.js` draws `.nc-step` and `.nc-pad` at the playhead with that ring (the step lifts with `z-index: 1`, since the ring is wider than `step-gap`). No transition: it follows the audio clock. `scripts/check-nc-ui.mjs` takes this patch back in a copy of the tree, then checks 1 and 2 against that copy.
4. `patches/nc-ui-note-overflow.patch` (upstreamable, on top of 1–3; it touches only the `.nc-note` rule). `.nc-note` gets `position: relative`. Each note carries the hidden `nc-token-probe` (an empty, absolutely positioned token probe, not screen-reader text). Without a positioned note its containing block lay outside the note, so the note's `overflow: hidden` did not clip it, and after a long one-line note it sat past the text's end and widened the page on phones. Now the note is its containing block and the clip holds it. No new values; the ellipsis and the note's text for screen readers are unchanged. Apply it from the nc-ui root with `patch -p1`. `scripts/check-nc-ui.mjs` takes it back in the same copy (after 5), then the playhead patch, then checks 1 and 2.
5. `patches/nc-ui-probe-safe.patch` (upstreamable, on top of 1–4; it touches only the `.nc-token-probe` rule). The cause behind 4, for every control: the probe is now pinned to its containing block's corner at zero size (`inset: 0 auto auto 0; width: 0; height: 0`), so a probe after a long one-line label (or in any unpositioned box) can no longer sit past the page edge. Controls that carry it: module, slider, select, toggle, button, readout, label, note, knob, choice, slotRow, stepGrid, canvas, fx. It keeps `background: accent` and `font-family: font-ui`, so token reads still resolve; `clip-path` is dropped (nothing to clip at zero size). The literal `0`s are unitless, which the domain lint allows (it flags px, rem and em). `scripts/check-nc-ui.mjs` takes it back after 6, then 4, then 3.
6. `patches/nc-ui-text-ellipsis.patch` (upstreamable, on top of 1–5; `kit.js` only). Astrid's call: a control's own text is one line with an ellipsis everywhere, so long text never widens the page or makes a control taller. A field label (`.nc-field .nc-label`) can now shrink (`flex: 0 1 auto`), but never below the name column (`min(rhythm.name-width, 100%)`), so short labels sit exactly where they did. A field value (`.nc-field .nc-readout`) never gives way to its label: it keeps its width (`flex: none`), so a long label beside a knob, slider or readout is cut first and `0.3` stays `0.3`; only a value longer than the row beside a name-width label is cut (`max-width: calc(100% - rhythm.name-width - rhythm.module-gap)`, `none` in the slider grid, whose value column is already `auto`). The value, `.nc-btn`, `.nc-toggle`, `.nc-choice` and `.nc-fx-name` get `min-width: 0`, `overflow: hidden`, `text-overflow: ellipsis` and `white-space: nowrap`. Slider rows keep the label column at least name-width wide (`minmax(min(rhythm.name-width, 100%), 1fr)`), so a long value is cut instead of hiding the label. A canvas beside a label keeps the width it has next to a column-wide label (`calc(100% - rhythm.name-width - rhythm.module-gap)`). Choice tabs stay on one line (`flex-wrap: nowrap`, was `wrap`); a tab that does not fit is cut, and under `@media (pointer: coarse)` a tab keeps `min-width` and `min-height` at `target-min` (the token the touch patch caps hit pads with), so a cut tab is still a full touch target; when the tabs cannot shrink further, the row scrolls within itself on a coarse pointer (`overflow-x: auto`, `scrollbar-width: none`, plus `::-webkit-scrollbar { display: none; }`), so seven or eight long tabs at 360 px never make the page scroll sideways and the last tab can be scrolled into view. Controls (knob, range, slot cells, canvas, select) keep their size, and a native select keeps its own option rendering; only its field label is cut. The full text stays in the DOM or `aria-label`, so accessible names are never cut. There are no title tooltips and no new values. `scripts/check-nc-ui.mjs` takes it back after 7, then 5, 4 and 3.
7. `patches/nc-ui-row-select-no-shift.patch` (upstreamable, on top of 1–6; `kit.js` only). Peter's P1: selecting a lane moved its step cells (about 4 to 6 px at the row's end), so the column grid broke. The lane's end handle (`.nc-len-handle`) was `display: none` on every lane but the selected one, where it took its own width (`rhythm.control-gap`) plus one more `rhythm.step-gap` inside `.nc-steps`, and the lane's 16 cells shrank to make room. Now every lane lays the handle out (`display: block`), hidden with `visibility: hidden` except on the selected lane (so it still cannot be focused or hit there), and it takes no width in the row: `margin-inline: calc((rhythm.control-gap + rhythm.step-gap) / -2)` cancels its own width and the gap it adds, so it sits centred in the gap after the lane's last step and lifts above the cells (`z-index: 1`) when shown. The beat gap is counted among the cells only (`:nth-child(4n + 1 of .nc-step-wrap)`), so a short selected lane, whose handle sits between cells, keeps its ghosted steps in the same columns as every other lane. The selected lane's tint, inset accent bar (`marker-width`) and underlined name were already layout-free and are unchanged. No new values. `scripts/check-nc-ui.mjs` takes it back after 8, then 6, 5, 4 and 3.
8. `patches/nc-ui-velocity-shade.patch` (upstreamable, on top of 1–7). Peter: an on step's fill is its velocity, continuous, 100% darkest. One shared mapping, `velocityFill(velocity, ramp?)` in `src/color.js` (pure; a number in, plain JSON `{ velocity, t, fill, ink }` out; Bass reuses it), clamps to the new constant `velocity-range` (`[0.05, 1]`) and runs linearly in OKLab from `rhythm.velocity-min` (new base `color.accent-velocity-min`, #477399: the accent's OKLCH hue and chroma, lighter) at 5% to `rhythm.velocity-max` (`color.accent`, #003153) at 100%. `velocityFillStyle` writes it to the new runtime token `velocity-fill` (`--nc-ui-velocity-fill`, default `color.accent-pad`, the plain on fill) on each step and pad; `patchSteps` writes it only when that cell's velocity changes (a WeakMap of the last value, so no work on a playhead step). `kit.js`: an on step or pad fills with `velocity-fill`; an accent no longer changes the fill and is a paper bar inside the bottom edge instead (`rhythm.accent-mark`, `semantic.on-accent`; `rhythm.accent-mark-size`, `space.3`; an inset box-shadow, no layout); a step or pad whose chance is below 100% (`data-dim`) gets a dashed border at the same width (`border-style: dashed`, `background-clip: padding-box`) and no opacity; a muted or soloed-out lane keeps `probability-dim`, and steps past a lane's length stay ghosted. `transition: none` as before. Contrast (WCAG): the 5% fill is 4.61:1 on paper, 3.67:1 on `accent-tint`, at least 3.26:1 on `module-bg-stack-1`…`4`; paper ink and the accent mark at least 4.61:1 on every fill. `test/velocity.test.mjs` holds the ends, clamping, monotonic order and those floors. Documented in `docs/domains/rhythm.md` (Velocity shade). `scripts/check-nc-ui.mjs` takes it back after 9, then 7, 6, 5, 4 and 3.
9. `patches/nc-ui-confirm.patch` (upstreamable, on top of 1–8). A shared confirm dialog for destructive actions (first user: Rhythm's Reset; Bass vendors it byte-identical). `confirm({ title, body, confirmLabel = "Confirm", cancelLabel = "Cancel", danger = false, root = document.body, returnFocus, signal }): Promise<boolean>` in `src/primitives/confirm.js` (+ `.d.ts`, exported from `src/index.js`), no dependencies, an in-app `role="alertdialog"` (never `window.confirm`). True only on the confirm button; Cancel, Escape, a backdrop tap, an aborted `signal` (an `AbortSignal`: closes it from code and cleans up like Cancel; already aborted never opens) and a second call while one is open are false; Cancel has focus, Tab and Shift+Tab stay on the two buttons, Enter acts on the focused one, the root's other children are `inert`, and on close focus goes to `returnFocus` (the opener; Safari on Mac does not focus a clicked button) or else back where it was. Self-contained (no `kit.js`): its styles are `src/primitives/confirm.css` beside it, which `confirm.js` links once per document (`<link rel="stylesheet" data-nc-ui-confirm>` from `new URL("./confirm.css", import.meta.url)`, at import and on each call; the URL is exported as `confirmCss`), so Bass vendors the two files and nothing else. `confirm.css` holds the `.nc-ui-confirm*` rules (semantic tokens only, each `var(--nc-ui-…)` with the token's current value as its fallback, so it renders the same with no nc-ui tokens loaded; 44 px buttons under `pointer: coarse`; fade in on `motion-fade`, out on `motion-fade-out`, scale on `motion-slide`; off under `prefers-reduced-motion`); `kit.js` has none of them. `test/confirm.test.mjs` checks every fallback against `dist/tokens.js`, and the token lint (`check:theme`) accepts a `.css` fallback only when it equals the token. New semantic tokens: `on-danger` (`{color.paper}`), `dialog-scrim` (ink at 35%, derived), `dialog-width` (320px), `dialog-pad` (`space.16`), `dialog-gap` (`space.12`), `dialog-button-gap` (`space.8`), `dialog-button-min` (`space.32`), `dialog-radius` (`radius.xs`), `dialog-leading` (`leading.readout`, 1.35; the dialog sets its own line height, so it is as tall without the app's page CSS). Documented in `docs/confirm.md`; `test/confirm.test.mjs` holds the tokens, contrast, CSS contract and the 2 KB gzip budget (`confirm.js`). Pins for apps that vendor it byte-identical (Bass): `src/primitives/confirm.js` sha256 `bfab001408fc55b12e0f624badc6dfbac4477236c26f915541ace5901afa291c`, `src/primitives/confirm.css` sha256 `1d27feeefef211edb27f6652f446390aaee6fd9a58b9b11f311a9f672ab5fad0`; `scripts/check-nc-ui.mjs` fails if a file and its pin differ. `scripts/check-nc-ui.mjs` takes it back first, then 8, 7, 6, 5, 4 and 3.
10. Local seams, not part of the domain patch: `src/alias.js` (the only file that names a custom property, and the place `tokens/renames.json` is applied; `filterPaint` is the only caller of the filter roles), `src/module/`, `src/primitives/`. The touch patch does include those seams, because that is where the shared controls live.

`src/alias.js` does not invent token values. Rhythm values come from the domain patch.
