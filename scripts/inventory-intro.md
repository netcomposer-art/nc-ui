## Base tokens still read by modules

The rule is that modules read semantic tokens and their own domain's component tokens, never base tokens. The extraction swapped literals for the nearest token, so many module lines still read a **base** token directly. Most are type sizes (`font-size-xs` / `font-size-sm`), letter-spacings (`tracking-*`) and the Tailwind bridge in `index.css`. The **contract preview** at the end of this file counts them per file. They aren't visual bugs. They're the to-do list for adding the missing roles (for example a `label-size` user for every uppercase label, a `hint-size`, and `tab-tracking`), and the module lint should start in warn mode with that count as its baseline. `index.css` is the Tailwind and shadcn bridge, which maps base values into Tailwind's theme. The suggestion is to move that bridge into nc-ui (`tokens.tailwind.css`) so that ASTRID's own CSS reads only roles.

## Inconsistencies found (top first), with the merge I'd suggest

Nothing below was changed; every one is kept exactly so the extraction is pixel-identical. Each merge is a visible change and needs Peter's OK.

1. **Two near-black inks.** Text is `#202523` (`color.ink`), surprise labels use `#1f2421` (`color.ink-label`, from `surprise.ts`), and the shadcn foreground is `hsl(156 7% 13%)`, a third approximation. *Merge:* everything onto `color.ink`.
2. **Five reds.** The danger red `hsl(8 55% 44%)` was typed inline on 26 lines across 8 files (situation-drawer, source-form, synth, configuration-controls, meaning-filter and three CSS files). Meaning's tension is `#A04A3F`, the band-pass curve is `#B8443A`, and Tailwind's `red-500/600/700` and `red-50/300/400` appear in the error, not-found and save screens. *Merge:* `danger` for errors and one data-red for curves/dimensions. Drop the Tailwind reds.
3. **Two ambers.** `#9A6B34` (warning, energy, override thumb) vs `hsl(38 50% 38%)` (stale status). *Merge:* one `warning`.
4. **Three disabled opacities.** A disabled slider is `.35`, a disabled control row is `.55` (inline in controls.tsx), a disabled hack-move arrow is `.3`. *Merge:* one `disabled-opacity`.
5. **Three font stacks and a stray mono.** NC uses `'Inter', 'Geist', sans-serif`, while body/shadcn use `'Inter', sans-serif`. The SVG curve labels (filter and envelope Hz/ADSR) use the generic `monospace`, not IBM Plex Mono. The history chart used `'IBM Plex Mono'` with no fallback. *Merge:* `font-ui` and `font-readout` only, and `synth.curve-label-font` points at `semantic.font-readout` (the curve-label glyphs would change).
6. **Too many type sizes.** 8 (SVG), 9, 10, 10.5, 11, 12, 13, 14, 15, 18, 20, 24 px, plus Tailwind's rem sizes (text-xs/sm/xl/2xl equal 12/14/20/24 px). `10.5px` is used once, and `15px` only for the h1. *Merge:* a 7-step scale (9, 10, 11, 12, 13, 18, 20) with the rem duplicates folded in.
7. **Too many letter-spacings.** .06, .08, .1, .12, .14, .15, .2, .28 em, plus −.01, −.22 and Tailwind −.025 em. *Merge:* four (label, title, wide, grip).
8. **Shading defined twice.** The hack-card shades lived both in index.css and in `HACK_SHADES` (lib/hack-stack.ts). Both now read `module-bg-stack-2..4`, so they can't drift. The Meaning areas use a separate −3 per channel ramp (`#F2F2EF`, `#EFEFEC`, `#ECECE9`, `#E8E8E5`) next to the modules' −5 ramp, and `#EFEFEC` vs `#EEEEEB` differ by one step. *Merge:* Meaning on the module ramp.
9. **One-off near-whites.** Drawer `#F1F1EE`, skeleton highlight `#EFF1EE`, white key `#FBFBF9`, held-key mix base `#FFFFFF`, manifest background `#ffffff`. *Merge:* paper / shade-1 / white.
10. **shadcn theme approximations.** background `72 13% 95%` (≈ #F3F4F0, vs paper #F5F5F2), primary `164 24% 34%` (≈ #426B60, vs accent #426C61), muted-foreground `146 4% 50%` (≈ #7B847F, vs sub #7C8580). Kept under `base.legacy.*`. *Merge:* point the shadcn vars at the NC semantic tokens.
11. **Bug.** `midi-file-player.tsx` line 60 uses `accent-[var(--nc-accent)]`, but that variable doesn't exist (the NC accent is `--nc-acc`), so the progress bar shows the browser's default accent. *Fix:* `accent-[var(--nc-ui-accent)]`. Visible, so not done here.
12. **Motion.** State changes use `motion-fade`, `motion-fade-out`, `motion-slide`, and `transition-feedback` (100–250 ms) and turn off under `prefers-reduced-motion: reduce`. A button press scales to .985. Slider thumbs and meters do not transition yet. A value an external source is driving carries `data-modulated`, and that control and its children jump.
13. **Canvas, Leaflet and Recharts can't read CSS variables.** They now import resolved token values from `@netcomposer/nc-ui/tokens`. A token change still lands in one place (tokens.json), but it needs a rebuild, not a live CSS swap.
